# Админка «Оплата» (`app/admin/payments-panel.tsx` + `app/api/admin/payments`)

- Таблицы **постранично по 10** (курсор по id, `?payments_before=`/`?recurrent_before=`).
- Автопродления: колонка «Дата подписки» (`created_at`) и **сортировка по всем колонкам** — клик по th, клиентская; при включении догружает все записи (`?recurrent_all=1`, до 1000; курсор несовместим с произвольным ORDER BY), пока сортировка активна — «Показать ещё» скрыта.
- Страница /admin шире сайта: breakout `max-w-6xl` из `max-w-4xl`.
- Счётчик автопродлений — `recurrentActiveStats()` (в т.ч. `renewed`: сколько активных продлились ≥1/≥2/≥3 раз по `success_streak`, в заголовке «Автопродления»; и `streaks` — полное распределение «продлений × тариф» включая 0, таблица под автопродлениями).
- Колонка «Способ» — `{prefix}payments.payment_method` (ЮKassa: «Visa •• 1234»/«SberPay»/«ЮMoney»; T-Bank NULL) и `recurrent_subscriptions.card_type/card_last4`.
- «Способы оплаты» — разбивка по всем оплаченным (`getPaymentMethodStats`: карты → «Банковская карта»; NULL → T-Bank/«ЮKassa — без данных»).
- Бэкфилл — «Подтянуть способы из ЮKassa» (POST `{action:"backfill-methods"}`, по `merchant_id`, ≤200 за раз, идемпотентно) и «Подтянуть серии» (`{action:"backfill-streaks"}` → `backfillRecurrentStreaks()`: пересчёт `success_streak` по оплаченным платежам с title `%(автопродление)%`, двухшаговый (агрегация SELECT → UPDATE по email-параметру, БЕЗ кросс-табличного сравнения строк — у payments от старого бэкенда иная коллация, подзапрос падает с «Illegal mix of collations»), идемпотентно).
- Блок «Динамика подписок» — последний блок страницы (под «Последние платежи», решение владельца 10.09); 5 SVG-лайнчартов (свои, без библиотек): новые подписки, продления, спрос по тарифам, способы оплаты и **провайдеры T-Bank vs ЮKassa (все её способы одной линией), во всю ширину**; данные `getSubscriptionStats(days)` в `lib/payments-store.ts` (продление = title `%(автопродление)%`, способы нормализует `methodBasketLabel()` — карты → «Банковская карта»), окна 7/30/90 (`?stats_days=`), **только завершённые дни — сегодня исключён** (иначе неполный день роняет хвост линий и бейджи роста), бейдж роста — сравнение с предыдущим таким же периодом.
